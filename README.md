# ARGO Float Explorer 🌊

A comprehensive oceanographic data analysis and visualization platform for ARGO profiling floats data.

## 🌊 Overview

ARGO Float Explorer is an advanced data analysis and visualization platform designed for oceanographic research using ARGO profiling float data. The system combines a sophisticated RAG (Retrieval-Augmented Generation) query interface with interactive visualizations to provide comprehensive insights into global ocean temperature, salinity, and biogeochemical parameters.

### Key Features

- **Interactive Dashboard**: Streamlit-based web interface for data exploration
- **Advanced Visualizations**: Temperature/salinity profiles, time series analysis, and trajectory mapping
- **RAG-Powered Queries**: Natural language database queries with AI assistance
- **Comprehensive Database**: 15 normalized tables supporting complete ARGO data lifecycle
- **NetCDF Processing**: Automated ingestion of profile, meta, and trajectory files
- **Quality Control**: Built-in QC flag handling and data validation
